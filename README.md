# IPCHEK

Монитор интернета, IP-адресов и VPN в строке меню macOS. При разрыве связи сразу присылает уведомление со звуком. Сделан как личный инструмент владельца, но поставить его может любой, у кого Mac на Apple Silicon с macOS 26. Проще всего — через Claude Code: раздел [«Установка через Claude Code»](#установка-через-claude-code).

**Состояние:** версия 0.7.0, сделаны этапы 1–5, 5а и 7 из 9. План и текущее состояние — [docs/PROJECT.md](docs/PROJECT.md).

## Что нужно

- macOS 26 на Apple Silicon.
- Xcode 26.6 (из App Store). Один раз открыть его и принять лицензию.
- XcodeGen: `brew install xcodegen`.

## Установка через Claude Code

Откройте Claude Code в папке этого репозитория и напишите: «Установи IPCHEK по README». Дальше — инструкция для Claude.

> **Claude Code:** вас попросили установить IPCHEK, а не разрабатывать его. Правила из `CLAUDE.md` — для разработки проекта, при установке их не применяйте. Делайте по шагам ниже.

1. **Проверьте Mac.** `sw_vers -productVersion` — 26 или новее, `uname -m` — `arm64` (Apple Silicon). Если не подходит — скажите человеку, что на этом Mac IPCHEK не установится, и остановитесь.
2. **Проверьте Xcode.** `xcodebuild -version` — Xcode 26.6 или новее. Если Xcode нет, попросите человека поставить его из App Store (это несколько гигабайт), один раз открыть и принять лицензию. Если команда пишет, что выбраны только Command Line Tools, — попросите человека выполнить `sudo xcode-select -s /Applications/Xcode.app` (нужен его пароль). Сами Xcode не ставьте.
3. **Проверьте XcodeGen.** `command -v xcodegen`. Если его нет — с согласия человека `brew install xcodegen` (нужен Homebrew).
4. **Предупредите человека, что сейчас будет:**
   - macOS спросит, можно ли IPCHEK присылать уведомления, — нужно нажать **«Разрешить»**. Без этого IPCHEK не сможет предупредить о разрыве связи;
   - macOS покажет уведомление о новом объекте входа — это автозапуск IPCHEK, так и должно быть;
   - в строке меню появится значок сети, клик по нему открывает панель.
5. **Установите:** `make install` в папке репозитория. Первая сборка занимает несколько минут. Команда положит IPCHEK в «Программы», включит автозапуск при входе в систему и запустит его.
6. **Проверьте вместе с человеком.** Пусть откроет панель (клик по значку в строке меню). Внизу должно быть «Уведомления разрешены» и кнопка «Тест» — она пришлёт пробное уведомление.
   - «Уведомления запрещены» — кнопка «Открыть настройки» → разрешить уведомления для IPCHEK;
   - «Уведомления: ждём вашего ответа» — человек ещё не ответил на запрос macOS;
   - «macOS не даёт включить уведомления» — раздел «Если уведомления не приходят» в [docs/OPERATIONS.md](docs/OPERATIONS.md).
7. **Свой VPN-сервер — по желанию.** Его адрес вписывается в «Настройки» → «Сервер в Нидерландах». Без него строка «Сервер NL» пишет «не задан», остальное работает.

Удалить IPCHEK — [docs/OPERATIONS.md](docs/OPERATIONS.md), раздел «Полное удаление».

## Запуск для разработки

```bash
make run
```

Команда соберёт отладочную версию и запустит её. В строке меню появится значок сети. При первом запуске macOS спросит, можно ли IPCHEK присылать уведомления, — нажмите «Разрешить».

Отладочная версия называется **IPCHEK Dev**. У неё свои настройки и своя история, рабочую версию она не трогает.

## Установка в «Программы»

```bash
make install
```

Рабочая версия **IPCHEK** окажется в «Программах» и запустится. При первом запуске macOS спросит, можно ли IPCHEK присылать уведомления, — нажмите «Разрешить»: без этого IPCHEK не предупредит о разрыве. Команда включает автозапуск: IPCHEK сам запускается при входе в систему и после сбоя (файл в `~/Library/LaunchAgents`). Вручную его можно запустить из Launchpad, через Spotlight или значком в Dock. Подробности — [docs/OPERATIONS.md](docs/OPERATIONS.md).

## Проверки

```bash
make verify
```

Проверяются оформление кода (swift-format), тесты логики и обе сборки — отладочная и финальная. Та же проверка запускается:
- перед каждым коммитом — включается один раз после клонирования командой `make hooks`;
- на GitHub при каждой отправке кода, вместе со сканером секретов.

Все команды: `make help`.

## Устройство

| Папка / файл | Что там |
|---|---|
| `App/` | приложение: значок, меню, уведомления |
| `Packages/IPCheckCore/` | логика без интерфейса и её тесты (`swift test`) |
| `project.yml` | описание проекта Xcode. Сам `IPCHEK.xcodeproj` генерируется командой `make project` и в git не хранится |
| `Makefile` | команды проекта |
| `scripts/git-hooks/` | проверка перед коммитом |
| `scripts/autostart.sh`, `scripts/autostart.plist` | автозапуск рабочей версии через launchd |
| `scripts/stop-app.sh` | штатное закрытие рабочей версии перед установкой |
| `.github/workflows/ci.yml` | автопроверки на GitHub |
| `docs/` | паспорт, решения, отложенное, эксплуатация, стандарт |

## Настройки и секреты

Секретов и переменных окружения у проекта нет, поэтому нет и `.env`. Настройки приложения хранятся в системных настройках macOS и проверяются при каждом запуске: неверное значение заменяется значением по умолчанию, замена записывается в журнал. Подробнее — [docs/OPERATIONS.md](docs/OPERATIONS.md).
