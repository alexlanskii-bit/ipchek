# IPCHEK

Монитор интернета, IP-адресов и VPN в строке меню macOS. При разрыве связи сразу присылает уведомление со звуком. Личный инструмент владельца, для одного Mac.

**Состояние:** версия 0.7.0, сделаны этапы 1–5, 5а и 7 из 9. План и текущее состояние — [docs/PROJECT.md](docs/PROJECT.md).

## Что нужно

- macOS 26 на Apple Silicon.
- Xcode 26.6 (из App Store). Один раз открыть его и принять лицензию.
- XcodeGen: `brew install xcodegen`.

## Запуск — одна команда

```bash
make run
```

Команда соберёт отладочную версию и запустит её. В строке меню появится значок сети. При первом запуске macOS спросит, можно ли IPCHEK присылать уведомления, — нажмите «Разрешить».

Отладочная версия называется **IPCHEK Dev**. У неё свои настройки и своя история, рабочую версию она не трогает.

## Установка в «Программы»

```bash
make install
```

Рабочая версия **IPCHEK** окажется в «Программах» и запустится. Команда включает автозапуск: IPCHEK сам запускается при входе в систему и после сбоя (файл в `~/Library/LaunchAgents`). Вручную его можно запустить из Launchpad, через Spotlight или значком в Dock. Подробности — [docs/OPERATIONS.md](docs/OPERATIONS.md).

## Проверки

```bash
make verify
```

Проверяются оформление кода (swift-format), тесты логики и обе сборки — отладочная и финальная. Та же проверка запускается:
- перед каждым коммитом — включается один раз после клонирования командой `make hooks`;
- на GitHub при каждой отправке кода, вместе со сканером секретов.

Все команды: `make help`.

## Устройство

| Папка / файл | Что там |
|---|---|
| `App/` | приложение: значок, меню, уведомления |
| `Packages/IPCheckCore/` | логика без интерфейса и её тесты (`swift test`) |
| `project.yml` | описание проекта Xcode. Сам `IPCHEK.xcodeproj` генерируется командой `make project` и в git не хранится |
| `Makefile` | команды проекта |
| `scripts/git-hooks/` | проверка перед коммитом |
| `scripts/autostart.sh`, `scripts/autostart.plist` | автозапуск рабочей версии через launchd |
| `scripts/stop-app.sh` | штатное закрытие рабочей версии перед установкой |
| `.github/workflows/ci.yml` | автопроверки на GitHub |
| `docs/` | паспорт, решения, отложенное, эксплуатация, стандарт |

## Настройки и секреты

Секретов и переменных окружения у проекта нет, поэтому нет и `.env`. Настройки приложения хранятся в системных настройках macOS и проверяются при каждом запуске: неверное значение заменяется значением по умолчанию, замена записывается в журнал. Подробнее — [docs/OPERATIONS.md](docs/OPERATIONS.md).
