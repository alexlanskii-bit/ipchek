# Эксплуатация IPCHEK

IPCHEK работает только на Mac владельца. Сервера, базы в облаке и секретов нет.

## Сборка и запуск для разработки

```bash
make run
```

Запускается **IPCHEK Dev** (`com.lavmoviesstudio.ipchek.dev`) — отдельное приложение со своими настройками.

## Установка рабочей версии

```bash
make install
```

Команда соберёт финальную версию, штатно закроет уже установленную копию (как кнопка «Выйти»), положит новую в `/Applications/IPCHEK.app`, проверит подпись, включит автозапуск и запустит IPCHEK. Это **IPCHEK** (`com.lavmoviesstudio.ipchek`) — со своими настройками, отдельными от IPCHEK Dev.

После первой установки один раз:
1. В запросе macOS разрешить уведомления.
2. Значок IPCHEK в строке меню → «Настройки» → вписать адрес VPN-сервера (у рабочей версии свои настройки, адрес из IPCHEK Dev сам не переносится).
3. По желанию — перетащить IPCHEK из «Программ» в Dock, чтобы запускать одним нажатием.

Запускать вручную: Launchpad, Spotlight (⌘ + пробел → «IPCHEK») или значок в Dock. Если IPCHEK уже работает, клик по значку в Dock открывает окно с его панелью. Не держите одновременно запущенными IPCHEK и IPCHEK Dev — уведомления будут приходить дважды.

## Автозапуск и перезапуск после сбоя

`make install` кладёт файл автозапуска `~/Library/LaunchAgents/com.lavmoviesstudio.ipchek.autostart.plist` (шаблон — `scripts/autostart.plist`) и запускает IPCHEK через launchd — системную службу запуска macOS. Дальше launchd:
- запускает IPCHEK при входе в систему;
- запускает его снова через 1–10 секунд, если он закрылся из-за сбоя.

Кнопка «Выйти» и выключение Mac — штатный выход: после них IPCHEK сам не запустится до следующего входа в систему. Если после «Выйти» запустить IPCHEK вручную, перезапуск после сбоя у этой копии заработает со следующего входа в систему.

При первой установке macOS покажет уведомление о новом объекте входа — это он.

Выключить автозапуск:
- в IPCHEK: «Настройки» → «Запускать при входе в систему» (действует со следующего входа);
- или в Системных настройках → Основные → Объекты входа → IPCHEK.

Если IPCHEK не запустился после входа в систему:
1. Проверить переключатель в настройках IPCHEK и в Системных настройках → Основные → Объекты входа.
2. Посмотреть, знает ли launchd о задании: `launchctl print gui/$(id -u)/com.lavmoviesstudio.ipchek.autostart` — строки `state` и `last exit code`.
3. Выполнить `make install` ещё раз: он заново положит файл и запустит IPCHEK.

Команды без переустановки: `scripts/autostart.sh stop` — закрыть IPCHEK и снять задание до следующего входа; `scripts/autostart.sh start` — положить файл и запустить; `scripts/autostart.sh remove` — снять задание и удалить файл.

## Сон Mac

Пока Mac спит и ещё 30 секунд после пробуждения IPCHEK не присылает уведомлений: Wi-Fi и VPN в это время переподключаются. Если и после паузы интернета нет или VPN не вернулся — уведомление придёт. Минуты сна не считаются временем без интернета. Длину паузы можно поменять: «Настройки» → «После пробуждения Mac молчать».

В журнале это строки категории `power`: «Mac засыпает», «Mac проснулся после … с сна».

## Обновление

1. `git pull`
2. `make verify` — должно закончиться строкой «✅ make verify: все проверки пройдены».
3. `make install`.

## Откат

1. Посмотреть версии: `git tag`.
2. Перейти на нужную: `git checkout <тег>`, затем собрать и установить её.
3. Вернуться к свежей версии: `git checkout main`.

## Журналы

Приложение пишет журнал в системный журнал macOS (подсистема `com.lavmoviesstudio.ipchek`, для отладочной версии — `com.lavmoviesstudio.ipchek.dev`). Запуск, автозапуск и выход — категория `launch`, сон и пробуждение — `power`.

- **Программа «Консоль»:** нажать «Начать», в поиске ввести `com.lavmoviesstudio.ipchek`.
- **Терминал**, в реальном времени (полный путь `/usr/bin/log` обязателен: в zsh есть встроенная команда `log` с тем же именем):

```bash
/usr/bin/log stream --predicate 'subsystem BEGINSWITH "com.lavmoviesstudio.ipchek"' --level info
```

Подробные строки о каждой проверке связи пишутся уровнем `debug`: macOS их не хранит, они видны только в реальном времени с ключом `--level debug`:

```bash
/usr/bin/log stream --predicate 'subsystem BEGINSWITH "com.lavmoviesstudio.ipchek"' --level debug
```

В журнал не пишутся адрес сервера в Нидерландах и прочие чувствительные данные.

## Где лежат данные

Приложение работает в «песочнице», поэтому все его данные лежат в одной папке:
- рабочая версия — `~/Library/Containers/com.lavmoviesstudio.ipchek/`;
- отладочная — `~/Library/Containers/com.lavmoviesstudio.ipchek.dev/`.

Сейчас там только настройки. С этапа 6 появится история.

Настройки меняются в окне «Настройки» (кнопка в панели). Кнопка «Вернуть значения по умолчанию» возвращает значения из паспорта. Если файл настроек повреждён, приложение при запуске возьмёт значения по умолчанию и запишет об этом в журнал.

**Резервная копия** — Time Machine, если она включена. Отдельных бэкапов нет: данные локальные и восстанавливаемые.

## Полное удаление

1. В папке проекта: `scripts/autostart.sh remove` — IPCHEK закроется, файл автозапуска удалится.
2. Удалить приложение из «Программ».
3. Удалить папку с данными (см. выше).
4. Разрешение на уведомления убирается в Системных настройках → Уведомления.

## Секреты и их смена

Секретов нет. Адрес VPN-сервера в Нидерландах хранится только в настройках приложения на этом Mac — не в коде, не в репозитории и не в журнале. Если сервер сменился, впишите новый адрес в настройках («Настройки» → «Сервер в Нидерландах» → «Сохранить»).

## Если строка «Сервер NL» пишет «не отвечает», а VPN работает

Сервер проверяется TCP-соединением напрямую через Wi-Fi/кабель на порты 443 и 22. Если на сервере открыт другой порт (например, только ваш VPN-порт или SSH на нестандартном порту), выберите в настройках «Только мой порт» и впишите его. Ping не используется: «песочница» macOS не даёт приложению принять ответ на него.

## Значок приложения

Рисуется скриптом: `make icon` перезаписывает `App/Assets.xcassets/AppIcon.appiconset`. macOS кэширует значки — после смены значка может понадобиться перезапуск приложения.

## Если уведомления не приходят

1. Системные настройки → Уведомления → IPCHEK (или IPCHEK Dev): уведомления должны быть разрешены.
2. Проверьте, не включён ли режим «Не беспокоить» / фокусирование.
3. Если приложения нет в списке или в журнале есть «Запрос разрешения на уведомления не удался» — macOS не принимает локальную подпись. Тогда нужно подписать приложение бесплатным Apple ID (см. docs/DECISIONS.md, решение 4).

## Лимит автопроверок GitHub

С 2026-11-07 репозиторий публичный, а для публичных репозиториев стандартные машины GitHub бесплатны — лимита минут нет (docs/DECISIONS.md, решение 43). Если GitHub всё же остановит проверки, денег не спишут (карта не привязана), а локальная проверка `make verify` и проверка перед коммитом продолжают работать.
