# Отложенное

## Функции «потом» (из паспорта, раздел 5)
- Виджет на рабочем столе.
- Уведомление на телефон (например, в Telegram) — отправляется, когда интернет вернулся.
- График задержки за сутки.
- Голосовое оповещение.
- Уведомления, которые проходят сквозь режим «Не беспокоить».
- Распространение другим людям (платная подпись Apple Developer, 99 $ в год).

## Мелкие доработки по итогам проверки этапа 1 (2026-11-06)
Найдены при разборе «уведомление не пришло». Причина была в порядке действий, не в коде: первое нажатие пришлось на время, когда уведомления в системе ещё были выключены. Предлагается сделать в начале этапа 2.
- **Журнал тестового уведомления.** Записи «отправлено» и «не отправлено: запрещены» писать уровнем `notice`. Уровень `info` macOS хранит только в памяти и быстро теряет, а ветка «не отправлено» сейчас вообще не пишет в журнал — из-за этого разбор занял лишние шаги.
- **Строка состояния уведомлений обновляется при открытии меню.** Сейчас она обновляется только по кнопке, поэтому после включения уведомлений в Системных настройках меню продолжает писать «запрещены».
- **Кнопка «Открыть настройки уведомлений»** в меню, когда уведомления запрещены. Перед этим сверить с документацией адрес раздела настроек для macOS 26.

## Инженерное
- **Статический анализ независимым инструментом** (стандарт, модуль Р: «например, Semgrep»). Поддержка Swift у Semgrep ограничена. Пока эту роль выполняют строгий компилятор Swift 6 (предупреждения = ошибки) и swift-format. Решить до фазы 4 (финальная проверка).
- **Сканер секретов перед коммитом на этом Mac.** Сейчас gitleaks работает только в автопроверках GitHub. Локально нужна установка через Homebrew — только с согласия владельца.
- **Строки интерфейса в String Catalog со склонениями** («1 разрыв, 2 разрыва, 5 разрывов»). Сделать, когда в текстах появятся числа (этапы 2–6).
