# Отложенное

## Функции «потом» (из паспорта, раздел 5)
- Виджет на рабочем столе.
- Уведомление на телефон (например, в Telegram) — отправляется, когда интернет вернулся.
- График задержки за сутки.
- Голосовое оповещение.
- Уведомления, которые проходят сквозь режим «Не беспокоить».
- Распространение другим людям (платная подпись Apple Developer, 99 $ в год).

## Инженерное
- **Статический анализ независимым инструментом** (стандарт, модуль Р: «например, Semgrep»). Поддержка Swift у Semgrep ограничена. Пока эту роль выполняют строгий компилятор Swift 6 (предупреждения = ошибки) и swift-format. Решить до фазы 4 (финальная проверка).
- **Сканер секретов перед коммитом на этом Mac.** Сейчас gitleaks работает только в автопроверках GitHub. Локально нужна установка через Homebrew — только с согласия владельца.
- **Строки интерфейса в String Catalog со склонениями** («1 разрыв, 2 разрыва, 5 разрывов»). Сделать, когда в текстах появятся числа (этапы 2–6).
- **Ограничить размер ответа проверочного адреса.** Сейчас ответ читается целиком, но не дольше 2 с (таймаут). Стандарт, модуль В, п. 10. Риск мал: ответы — от 0 до 11 байт. С этапа 5а есть готовый `BoundedBody` — им ограничены ответы служб IP и стран.
- **Разные службы стран для вашего IP и IP VPN** (решение 35). Сейчас ipinfo и ipapi получают запросы о двух адресах с промежутком от минуты — связать их можно только по времени. Чтобы убрать и это, нужны четыре службы стран вместо двух — только с согласия владельца.
- **Жёлтый значок на светлой строке меню.** Проверить на глаз контрастность `systemYellow`; при необходимости — оранжевый.
- **Память ~87 МБ** при цели «меньше 100 МБ» — следить на следующих этапах.

- **Проверка уведомлений без отключения Wi-Fi.** Сейчас разрыв можно проверить только руками (выключить Wi-Fi или выдернуть кабель роутера). Возможный вариант — режим имитации разрыва только в отладочной сборке. На этапе 7 сон и смена сети покрыты сценарными тестами, имитация не понадобилась; вернуться, если ручные проверки станут частыми.
- **Перезапуск после сбоя для копии, запущенной вручную** (решение 38). Если закрыть IPCHEK кнопкой «Выйти» и запустить снова из Dock, эта копия работает не под присмотром launchd до следующего входа в систему или `make install`. Возможный вариант — ручной запуск просит launchd запустить задание через файл-сигнал (`WatchPaths`); Apple не советует этот ключ — нужен запасной путь.
